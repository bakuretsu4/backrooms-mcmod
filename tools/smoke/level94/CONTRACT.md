### Lore (wiki)
- **Look:** grainy and "crafted", like a stop-motion set. The user chose a SUBTLE crafted look: handmade textures (felt-like grass with mowing stripes, cardboard or painted siding, oversized bricks), slightly over-saturated, toy-like.
- **Landscape:** endless rolling green hills and winding roads, with odd cars parked in the middle of nowhere and water towers.
- **Fragments:** random fragments of houses on the hills, such as a lone wall with furniture next to it or a single room.
- **Houses:** all alike. Off-white, one door and two windows in front, oversized bricks along the base, flat and billboard-like. Gable roofs in brown or red.
- **House interiors:** mostly empty but colourful, like a children's TV set. A cushioned chair, a bright rug (sometimes printed with toy roads), an odd-shaped lamp, and a CRT TV showing static.
- **Town:** a cluster of tiny 1930s-50s houses with 1930s cars and white milk vans.
- **Fountain:** at the town centre, a big almond-water fountain shaped like a king chess piece.
- **Siren poles:** play happy cartoony music on loop during the day. At night the music stops and it goes quiet.
- **Castle:** on a transparent glass mountain, visible from everywhere. Inside, the cartoon look fades and things look realistic but wrong. It is a funhouse / kids' play centre: checker floors, striped pillars with porthole circles, crawl tubes, ball pits, playgrounds, slides, halls that loop.
- **Animation studio:** inside the castle, with a miniature replica of the town and sketches on the tables.
- **Throne room:** reached through a large doorway. It is empty (no King in this version), and the light behind the throne sends you on.

## User decisions
- Scope: the world plus a day/night cycle. No new monster. At night Smilers (an existing entity) come out.
- The castle is REACHABLE and has the funhouse inside.
- Way in: a rare CLAY DOOR on Level 9 houses leads to Level 94.
- Ways out:
  - Rare "dark-door" houses in Level 94 lead to Level 9.
  - The castle throne room's light leads to Level 1.
- Cycle: 8 min day (last 30 s = dusk) and 3 min night (last 20 s = dawn). Already written: `world/Level94Clock.java`.

## Cross-slice APIs (exact signatures; implement exactly so the other slices compile)

### Castle slice → `world/layout/Level94Castle.java` (final class, static methods)
```java
public static final int REGION = 1024;          // one castle per 1024x1024 region
public static final int MOUNTAIN_RADIUS = 64;   // glass mountain base radius at ground level
public static final int CLEAR_RADIUS = 84;      // World keeps ground flat (grass top y40) and builds nothing of its own within this distance of a castle centre, except the castle road
public static final int MOUNTAIN_TOP_Y = 150;   // plateau surface
public static final int CASTLE_TOP_Y = 215;     // highest spire tip
public static int[] centre(long seed, int regionX, int regionZ);   // {x, z}; at least CLEAR_RADIUS + 64 from the region's edges
public static int[] nearest(long seed, int x, int z);              // {x, z} centre of the nearest castle (check 3x3 regions)
public static int[] rampFoot(long seed, int cx, int cz);           // {x, z, dirX, dirZ}: ground point just outside CLEAR_RADIUS where the castle road must arrive, and the unit outward direction (dirX/dirZ in -1..1)
public static boolean fillColumn(long seed, int x, int z, LevelLayout.Column out);  // writes mountain/ramp/castle blocks; returns false (writes nothing) if (x,z) is farther than CLEAR_RADIUS from the nearest castle
public static boolean isThroneLight(long seed, int x, int y, int z);  // true inside the exit light volume behind the throne
public static boolean isInsideCastle(long seed, int x, int y, int z); // true inside the castle building (interior volume)
public static double standY(long seed, int x, int z);             // feet Y on the ramp/plateau/castle ground floor for that column, or NaN if not a castle walkable column (used for arrival/searchWalkable if needed)
```
- Inside CLEAR_RADIUS, World writes the flat ground (y≤40) first and then calls `Level94Castle.fillColumn`. Later writes win, so Castle may overwrite any Y.
- Between `MOUNTAIN_RADIUS` and `CLEAR_RADIUS` Castle may add a flat plaza or gate area. The road from `rampFoot` inward to the ramp start is Castle's job. World's road must reach `rampFoot`.

### Props slice → blocks in `registry/ModBlocks` plus helper classes
- `ModBlocks.L94_SIREN_POLE` (`DeferredBlock<PoleBlock>`): weathered wooden pole, placed as a vertical stack.
- `ModBlocks.L94_SIREN` (`DeferredBlock<SirenBlock>`): the horn speaker on top of the pole. `SirenBlock.FACING` (horizontal, the way the horn points). It has a block entity that plays the looping siren song on the client at `Level94Clock.musicVolume`.
- World places a siren pole as poles at ground+1..ground+7 and `L94_SIREN` at ground+8.
- Vehicles: `block/Level94Vehicles.java` (final, static):
```java
public enum Kind { CAR_RED, CAR_BLACK, CAR_CREAM, MILK_VAN }   // also a StringRepresentable block property on the anchor block
public static final int REACH = 3;   // footprint never extends more than 3 blocks from the anchor in x or z
/** The block for the cell at (dx, dy, dz) from a parked vehicle's anchor (dy = 0 is the ground layer it stands on, i.e. feet level), or null if that cell is outside the vehicle. */
@Nullable public static BlockState cell(Kind kind, Direction facing, int dx, int dy, int dz);
```
- Vehicle blocks: the anchor `ModBlocks.L94_VEHICLE` has a BER that draws the whole vehicle. `ModBlocks.L94_VEHICLE_HULL` is an invisible collision filler.
- World decides where vehicles go and fills each cell from `cell(...)` for dy = 0..3 at feet level.
- `ModBlocks.L94_TV`: CRT TV with an animated static screen, `FACING` = the screen side (FurnitureBlock-style). World places it in house interiors.
